# Plank Cooking

A college web project built with **ASP.NET Core**, **Angular** and **TypeScript**, bundled with **Webpack**.

## Structure
- `Controllers/`, `Api/`, `models/`: ASP.NET Core back end
- `ClientApp/`: Angular / TypeScript front end
- `Views/`, `wwwroot/`: pages and static assets

## Run
Requires the .NET Core SDK and Node.js: `npm install`, then `dotnet run`.
